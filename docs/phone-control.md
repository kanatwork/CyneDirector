# Codex from a phone — clarified scope

Confirmed by Kanishkar on 24 November 2026:

The phone is for using **Codex to give development prompts, review progress and
continue building CyneDirector**. It is not a required CyneDirector product surface.

CyneDirector targets desktop on Apple Silicon Macs and Windows PCs. A mobile UI,
phone-originated indexing jobs, phone previews, remote processing dashboard and
custom mobile/web API are outside current product scope. Local jobs/CLI remain
useful desktop infrastructure.

Codex mobile setup is a separate development-environment task. The earlier
provisional ChatGPT pairing/menu walkthrough has been retired; those connection
steps were not verified for the current Codex surface. No new connection setup
was performed as part of product discovery.

See [buildplan.md](../buildplan.md) and the [questionnaire](product-discovery.md).
Phone-operation points in historical audits belong to the previous, incorrectly
scoped product rubric.
